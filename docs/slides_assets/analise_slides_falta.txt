TÍTULO: Referencial teórico: BMC e ESBMC-Python

Bounded Model Checking (BMC):
- Verifica propriedades dentro de um limite finito k de execução.
- Traduz programa + negação da propriedade em fórmula lógica: C ∧ ¬P
  (C = restrições do programa · P = propriedade de segurança)
- SAT → solver SMT encontra contraexemplo concreto → BUG CONFIRMADO
- UNSAT → sem violação dentro do limite k

Fluxo interno do ESBMC-Python:
  Código Python
    → Parser gera AST
    → Inferência de tipos
    → Representação GOTO
    → Forma SSA
    → Fórmula SMT
    → Solver

Flags usadas neste trabalho:
  --function            verifica só a função indicada pelo modelo
  --assign-param-nondet entradas = valores desconhecidos (simbólico)
  --incremental-bmc     limite cresce gradualmente (mais eficiente)

Saídas:
  VERIFICATION FAILED + contraexemplo  →  bug confirmado (VP)
  VERIFICATION SUCCESSFUL              →  suspeita refutada (FP eliminado)
  Timeout                              →  inconclusivo

Referências: Biere et al. (1999); Cordeiro et al. (2012);
Gadelha et al. (2018); Farias et al. (2024).
