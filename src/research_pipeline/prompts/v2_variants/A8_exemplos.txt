The examples below show the format and the criterion; they are unrelated to the function you will analyse.

Example 1: reachable exception, reported.

def target_function(scores, k):
    top = sorted(scores, reverse=True)
    return top[k - 1]

Example 2: dangerous operation that is guarded, nothing to report.

def target_function(total, count):
    if count == 0:
        return 0.0
    return total / count

{"findings": []}
The division is only reached with count different from zero: the guard blocks exactly the value that breaks.
