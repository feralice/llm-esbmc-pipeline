## EXEMPLOS RESOLVIDOS

Os exemplos abaixo mostram o formato e o critério; não têm relação com a função que você vai analisar.

Exemplo 1: exceção alcançável, reportada.

def target_function(scores, k):
    top = sorted(scores, reverse=True)
    return top[k - 1]

Exemplo 2: operação perigosa protegida, nada a reportar.

def target_function(total, count):
    if count == 0:
        return 0.0
    return total / count

{"findings": []}
A divisão só é alcançada com count diferente de zero: a guarda bloqueia exatamente o valor que quebra.
