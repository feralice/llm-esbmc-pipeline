## INPUT PARTITION

Before item 1, go through each parameter and each attribute of `self` the function
reads and ask, one by one, what happens when it is:
- None (including when the parameter defaults to None or the name suggests it is optional);
- empty (string, list, dict, set);
- zero or negative;
- of another plausible type (bytes instead of str, int instead of str, list instead of tuple);
- a key missing from a dict, or an index out of range.
Each case that leads to an exception or a wrong result and passes the existing
guards is a hypothesis.
