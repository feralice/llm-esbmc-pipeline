## CALLS IN THE REPOSITORY

After the function comes an `UNTRUSTED_CONTEXT_CALLERS` block, taken from the repository's
call graph: each place that calls the function, with a few lines around it. Use it to decide
which values actually reach the parameters (does the caller already filter, convert or ensure
something?). When every caller blocks the value that breaks, do not report the finding. When the
block says no call was found, the function may be called from outside the repository with any
input compatible with its signature. It is not the function under analysis: do not report
findings about the callers' code.
